# Discord Store Bot Base Clean

Base limpia para crear bots de tiendas y comunidades de Discord.

## Uso local

```bash
npm install
npm start
```

Configura el token con `DISCORD_TOKEN` o en `config.json` solo para pruebas locales.

## Archivos importantes

- `config.json`: marca, roles, canales, tickets, sorteos, reseñas, redes y setup.
- `SETUP_BASE.txt`: guia de personalizacion.
- `data/`: datos runtime vacios para tickets, sorteos, reseñas y sugerencias.

No subas `node_modules`, `.env` ni tokens a GitHub.
